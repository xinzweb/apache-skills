## Project

- Repo: `apache/cloudberry` — https://github.com/apache/cloudberry — GitHub-native
  (Issues, Discussions, Wiki). **No separate JIRA tracker.**
- Status: Apache Cloudberry (Incubating), sponsored by the Apache Incubator.
  Standard disclaimer: "Apache Cloudberry is an effort undergoing incubation at
  The Apache Software Foundation (ASF), sponsored by the Apache Incubator...
  it does indicate that the project has yet to be fully endorsed by the ASF."
- Governance file: `.asf.yaml` at repo root (branch protection, merge policy,
  GitHub-notification routing — auto-applied by Apache Infra).

## Mailing lists

| List | Purpose | Subscribe | Archive |
|---|---|---|---|
| `dev@cloudberry.apache.org` | Primary technical/decision channel — proposals, bugs, docs, releases | `dev-subscribe@cloudberry.apache.org` | https://lists.apache.org/list.html?dev@cloudberry.apache.org |
| `private@cloudberry.apache.org` | PPMC-only — committer/PPMC nominations, sensitive matters | (PPMC roster add, not self-serve) | not public |
| `commits@cloudberry.apache.org` | Automated GitHub notifications (commits/issues/PRs) | `commits-subscribe@cloudberry.apache.org` | https://lists.apache.org/list.html?commits@cloudberry.apache.org |
| `general@incubator.apache.org` | Incubator PMC (IPMC) — podling reports, release votes | via incubator.apache.org | https://lists.apache.org |

Subject-tag conventions on `dev@`: `[DISCUSS]` (consensus-building), `[VOTE]`
(formal vote), `[PROPOSAL]` (lazy-consensus proposal), `[RESULT][VOTE]`
(outcome after a vote closes). Apache Way: **"if it didn't happen on the
mailing list, it didn't happen"** — Slack/Discord/GitHub exploration is fine,
but binding decisions belong on `dev@`.
